## Stages (with acceptance criteria)

**Stage 0 — Setup (~1h)**
Create structure from CLAUDE.md, `requirements.txt`, `.gitignore` (data/, .env), `config.py`, `.env.example`, git init.
Done when: `pytest` runs (even with 0 tests) and `ruff check .` passes.

**Stage 1 — Data layer (~3h)**
`fetch.py` downloads universe prices (adjusted close) and macro (FRED series + VIX), caches parquet, handles missing tickers/dates, aligns calendars.
Done when: one command builds the cache; test checks no NaN gaps after alignment and macro is lagged by release date.

**Stage 2 — Features and targets (~5h)**
`engineer.py`, `targets.py`, `portfolios.py` (random-weight synthetic portfolios; user-portfolio builder).
Done when: leakage tests pass (shifting future data must not change features at t; targets use only t+1..t+H), and a feature matrix exists for N synthetic portfolios.

**Stage 3 — Baselines (~3h)**
Historical VaR, parametric VaR, GARCH(1,1) vol forecast, naive vol (current realized vol).
Done when: baselines produce predictions on the same index as ML targets and pass through `evaluate.py`.

**Stage 4 — ML models (~8h)**
RF baseline → XGBoost (with quantile objective for VaR) → LSTM in PyTorch (windowed sequences, early stopping on val).
Done when: each model trains via walk-forward CV and saves artifacts to `models/artifacts/`.

**Stage 5 — Evaluation (~4h)**
Unified metrics table across all models/baselines, VaR backtest (Kupiec), plots (pred vs actual, error over time, stress periods such as 2020 and 2022), feature importance.
Done when: `reports/` contains the comparison table and figures; we can state clearly where ML beats or fails against traditional models.

**Stage 6 — Dashboard (~6h)**
Streamlit: ticker + weight input (validate weights sum to 1), predicted vol / drawdown probability / VaR, historical risk charts (Plotly), portfolio composition pie, model selector, comparison with baseline.
Done when: app runs from saved models without retraining and handles bad tickers gracefully.

**Stage 7 — Report (~5h)**
Results, methodology, limitations (delayed data, regime shifts, synthetic-portfolio training), README with run instructions, demo screenshots.
